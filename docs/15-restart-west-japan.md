## 採用方針

GitHub Pages、GitHub Actions、非公開Sheets、GASを維持する。県ごとの発見方法と許可URLを明示し、共通の文字抽出・根拠検証・重複処理を共有する。動的サイトは公開ページを描画する補助取得を使い、会員限定情報・認証APIは取得しない。

新候補は安定したIDで確認待ちEventsとReviewQueueに保存する。同じ候補の再取得は既存行を更新し、追記を増殖させない。自動抽出値はAutoFieldValuesへ保存し、管理者修正値はFieldOverridesへ保存する。公開・非公開など管理者の判断を自動処理で変更しない。

県別に取得成功・失敗・技術保留・候補0件を区別する。Sourcesの停止設定を日次収集にも反映する。日次処理は地域ごとに分割し、同じSheets行への競合を避けて順次処理する。取得キャッシュはローカルの非公開作業領域に保存する。公開リポジトリのActionsキャッシュへ本文は置かない。公開処理は全地域の完了後に一度行う。

AIはHTML/PDFの構造理解を補助し、返された根拠を入力本文と照合する。日時・参加費・単位に根拠がなければ採用しない。URLは取得文書内のものだけを認める。AIの確信度だけで料金を確認済みにしない。API接続は専用キーの保存が完了してから行う。
